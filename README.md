# chim

This is a Self-Modifying JIT LLM, just as a PoC.

## What does it do?

chim embeds an LLM model (qwen3.5-2b, in this case) along with llama.cpp and libtcc into a single program. A prompt to one-shot generate a program is fed into the LLM; the output of the LLM is JIT compiled into a valid binary inside the same program's space. We then execute the new program directly from memory.

## Why?

This would theoretically provide a state of obfuscation where there is genuinely no program before runtime. In addition, it would enable for a "LLM-to-binary" system (that people keep shilling). 

## Risks?

It is not recommended to run this software outside of a VM. The risk of UB being generated by a 2b model is extraordinarily high. You have been warned.
